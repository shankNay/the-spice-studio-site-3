# The Spice Studio — Modern Minimal

This is the updated static website package. It preserves the selected Modern Minimal design, imagery, hero video, transitions, and animations.

## WhatsApp lead forms

The Event Quote, Table Reservation, and General Enquiry forms now open WhatsApp addressed to **+91 89048 93793**, with the visitor's entered details formatted into a message.

**Important:** The form does not send a message silently. WhatsApp requires the visitor to press **Send** in WhatsApp to deliver the enquiry. On mobile, the link should open the WhatsApp app when installed; on desktop, it generally opens WhatsApp Web/Desktop. If a browser blocks the new window, allow pop-ups for the website and submit again. The standalone WhatsApp Enquiry buttons also open a direct chat.

This removes the unreliable email relay dependency. No backend or email credentials are required.

## Publish on GitHub Pages

1. Extract this ZIP.
2. Open the `the-spice-studio-modern` folder.
3. Upload the **contents of this folder** to the root of your existing GitHub repository (so `index.html` is at the repository root).
4. Replace the existing `index.html`, `styles.css`, `script.js`, and the complete `assets` folder.
5. Commit the changes. Your existing GitHub Pages URL and settings should remain the same.
